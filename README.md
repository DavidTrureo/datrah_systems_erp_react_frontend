# Datrah Systems ERP - Frontend 🚀

¡Bienvenido al repositorio del Frontend de **Datrah Systems ERP**! 
Este proyecto está desarrollado con las últimas tecnologías web para ofrecer una interfaz rápida, moderna y escalable, orientada a la gestión y facturación de la empresa.

## 🛠️ Tecnologías Utilizadas

- **React 19** - Librería principal para la construcción de interfaces de usuario.
- **TypeScript** - Superconjunto de JavaScript que añade tipado estático para un desarrollo más robusto.
- **Vite** - Empaquetador ultrarrápido y servidor de desarrollo.
- **React Router DOM v7** - Enrutamiento dinámico para la navegación de la aplicación.
- **Recharts** - Librería para la visualización de datos, métricas y gráficos del ERP.
- **Lucide React** - Conjunto de iconos limpios y modernos.
- **Oxlint** - Linter extremadamente rápido para mantener la calidad del código.

## 📦 Instalación y Configuración

Sigue estos pasos para configurar y ejecutar el proyecto en tu entorno local:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/DavidTrureo/datrah_systems_erp_react_frontend.git
   cd datrah_systems_erp_react_frontend
   ```

2. **Instalar las dependencias:**
   Puedes usar `npm`:
   ```bash
   npm install
   ```

3. **Ejecutar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Abrir en el navegador:**
   La aplicación estará disponible por defecto en `http://localhost:5173/`.

## 🚀 Scripts Disponibles

En el directorio del proyecto, puedes ejecutar:

- `npm run dev`: Inicia el servidor de desarrollo local con recarga en caliente (HMR).
- `npm run build`: Compila la aplicación y sus dependencias estáticas de TypeScript para producción de forma optimizada.
- `npm run preview`: Previsualiza la versión de producción generada en local tras hacer un build.
- `npm run lint`: Ejecuta el linter (Oxlint) para analizar el código en busca de posibles problemas.

## 📂 Estructura del Proyecto

El código fuente principal se encuentra en la carpeta `src/`, que actualmente contiene:
- `pages/`: Vistas principales y rutas de la aplicación (ej. `Login.tsx`).
- `assets/`: Recursos estáticos.
- *Nota: Esta estructura crecerá incorporando componentes, hooks, servicios y contextos.*
